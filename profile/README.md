# Stonewall

Stonewall is a private application for searching and reading legal source
records, working with matter records, and researching the record through
source-linked conversations.

- **Public site:** [stnwl.ai](https://stnwl.ai)
- **Workspace:** [app.stnwl.ai](https://app.stnwl.ai) (authenticated access)
- **Product repository and Wiki:** [stnwlai/Stonewall](https://github.com/stnwlai/Stonewall) · [Wiki](https://github.com/stnwlai/Stonewall/wiki) (authorized repository access)
- **Executable evidence reference:** [stnwlai/stnwl.ai](https://github.com/stnwlai/stnwl.ai)

The public reference uses fictional records to demonstrate citation checks,
quotation attribution, reproducible evidence bundles, retrieval, and example
disclosure rules. It runs locally without model calls or network access.
Its checks do not establish whether an answer is a fair or legally sound
reading of a source, and it does not contain the private application or corpus.
