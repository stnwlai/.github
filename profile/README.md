# Stonewall

**Institutional memory for a legal practice, built to be trusted.**

Stonewall is a private working application for finding, reading, and
reasoning from a complete legal record: retained source documents, searchable
text with its provenance, structured relationships between people, matters,
dates, and recurring subjects, and research conversations that stay connected
to the sources that answered them.

- **Public site:** [stnwl.ai](https://stnwl.ai)
- **Product repository and Wiki:** [stnwlai/Stonewall](https://github.com/stnwlai/Stonewall) · [Wiki](https://github.com/stnwlai/Stonewall/wiki)
- **Executable evidence reference:** [stnwlai/stnwl.ai](https://github.com/stnwlai/stnwl.ai) — the smallest runnable demonstration of the evidence contracts the product is built on (content-addressed evidence, line-verifiable citations, explainable retrieval, a fail-closed publication boundary)

How it is built: source documents are preserved with digests; searchable text
carries a quality label and points back to its original; answers cite the
record and show where the record is missing, disputed, or stale; private
material stays on a protected data plane; public pages carry only material
approved for public use; releases are reversible and verified against the
running revision.
